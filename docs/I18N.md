# i18n (i18next)

Client-side framework: `i18next` + `react-i18next`.

| Piece | Path |
| --- | --- |
| Config | `lib/i18n/index.ts` |
| Provider | `components/i18n/I18nProvider.tsx` (wired in `app/layout.tsx`) |
| Switcher | `components/i18n/LocaleSwitcher.tsx` (Settings → Language) |
| Strings | `locales/en-US/common.json`, `locales/es/common.json` |

**Locales today:** `en-US` (default) + `es`. Preference stored in `localStorage` (`garageGenius_locale`).

**Scope:** UI chrome (Coach Library headers, step feedback, onboarding welcome, settings). Production playbook JSON steps remain authored in English for now — expand with locale-specific scenario packs later.
